# vps-scripts

Small, tested scripts and notes for running a Linux VPS. Each folder has its own README.

| Folder | What it does |
|---|---|
| [monitoring](monitoring/) | Disk and RAM alerts to your phone (ntfy + cron), and how to find out why a server went down |
| [cloudpanel](cloudpanel/) | Installing CloudPanel safely: hash check, admin before anyone else, first site from the CLI |
| [lemp-lamp](lemp-lamp/) | LEMP vs LAMP on Debian/Ubuntu: when to pick which, install commands, RAM check |

Tested on Debian 12 and Ubuntu 24.04. Use at your own risk and read a script before you run it.
